## 🙋‍♀️ About Me

- 사용자 흐름을 살펴보고 더 적합한 UI와 개선 방향을 제안합니다.
- 반복되는 UI와 로직을 공통화해 **재사용성과 유지보수성**을 높이는 데
관심이 있습니다.
- SaaS, 헬스케어, 화장품 이커머스, 예약·리뷰 플랫폼 개발 경험이
있습니다.
- 개발 과정과 문제 해결 방법을 공유하며 더 나은 협업 방식을
고민합니다.
